# Baraka Design Excellence Skill
Use for visual quality, UX refinement, and interface implementation.

- Every visual element must have a functional reason.
- Prioritize information hierarchy, cashier speed, scannability, and error prevention.
- Maintain the approved Light/Dark, Arabic/French, typography, spacing, and contrast rules.
- Preserve consistent component states: default, hover, focus, disabled, loading, empty, error, success.
- Do not invent a new visual language inside a Task. Extend the approved design system.
