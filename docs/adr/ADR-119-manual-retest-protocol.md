# ADR-119 — بروتوكول إعادة الاختبار اليدوي لمسار الآجل والمخزون (نتيجة AUD-061)
**الحالة:** PROPOSED (يُعتمد مع V0-3). **التاريخ:** 2026-11-15.
**السياق:** AUD-061 أثبت عدم وجود عطل في المحرك (F-B4 منع صحيح، F-B1 مسار
مختبر 4/4)؛ الملاحظتان البصريتان تُعزيان لخلل الإدخال الآلي. لا إصلاح قبل
إعادة الإنتاج اليدوية (regression law).

## القرار
1. يُنفَّذ سيناريو AUD-061 §4 يدويًا على قاعدة عزل قبل أي `BRK-118`/`BRK-119`.
2. عند إعادة الإنتاج: `BRK-118`/`BRK-119` باختبار يفشل أولًا + G1–G7.
3. عند عدم الإنتاج: تُغلق R1/R2 بإثبات (لقطة + رقم مستند) دون كود.
4. ملاحظة UX المثبتة (انهيار المجاميع إلى `...`) تُنفَّذ ضمن `DSN-107` (R3).

## البدائل المرفوضة
- إصلاح استباقي للمحرك دون إثبات — مرفوض (خطر انحدار مالي بلا مبرر).
