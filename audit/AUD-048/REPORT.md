- **F4 (طفيف — قرص):** `release-v1.0.0/` على القرص ~1.9GB ملفات تجاهلها git

- **F5 (نظيف):** إصابة TODO الوحيدة إيجابية-كاذبة (`05XXXXXXXX`).
