# DOC-001 — إعادة هندسة وتصميم الوثائق المطبوعة (دراسة + مقترح)

- النطاق: كل ما يخرج على الورق — ملصق `40×20` (TSPL)، تذكرة `80مم` (TSPL)، تذكرة graphique (HTML)، مستندات A4، والمعاينات.
- المنهج: قياس الواقع من الكود والصور الحية، مقارنة بمعايير أنظمة الـPOS الكبرى، ثم مقترح مُرقّم بمعايير قبول.
- القاعدة الذهبية: **المعاينة تكذب اليوم** — HTML/SVG تقريبية، والحقيقة هي بايتات TSPL فقط.

## 1) الجرد الدقيق (الواقع كما هو)

### 1.1 ملصق `40×20` — `render_label_40x20` + `mixed` (بعد PRT-02)

| العنصر | الهندسة الحالية | الحكم |
|---|---|---|
| الأبعاد | `320×160` نقطة (`8` نقاط/مم) | سليم |
| المتجر | `TEXT "1"` عند `y=2` وسط | سليم (سطر مجهري مقصود) |
| الاسم | `TEXT "2"` عند `y=16` (سطر ثانٍ `y=38`) | سليم |
| الاسم العربي | `BITMAP` بمحاذاة سفلية لنفس الصندوق | يعمل (صغير بحكم الصندوق `300×24`) |
| السعر | `TEXT "5"` أصلي `32×48` عند `y=58` | سليم بعد التلميع |
| العملة | `x=272` (هامش 3مم) | سليم بعد التلميع |
| الباركود | `y=106 h=38` بلا سطر تلقائي + `TEXT y=146` وحيد | سليم بعد التلميع |
| الإنهاء | `PRINT 1,1\r\n` دائماً | سليم (قانون CRLF) |
| الفشل | صاخب (`LABEL_TEXT_UNPRINTABLE`…) | سليم |

### 1.2 تذكرة `80مم` TSPL — `render_ticket_80mm` (طول متغير)

| العنصر | الواقع | الحكم |
|---|---|---|
| العرض/الهوامش | `640` نقطة، هامش `16` | سليم |
| الترويسة | متجر `"3"` + عنوان/هاتف/ضرائب `"1"` تنهار عند الفراغ | سليم |
| السطور | تسمية `"2"` + تفاصيل `"1"` يميناً، شارة خصم | سليم |
| المجاميع | `"2"` يميناً + `TOTAL TTC` مميز | **ثغرتان (أدناه)** |
| الباركود | رقم المستند، مناطق هدوء `≥20` | سليم هندسياً |
| التذييل | رسالة المالك + شكر ثابت | سليم |

**الثغرة الحرجة T1 — العربية الصامتة:** التسميات والتعليقات العربية (`TsplCaptionLang::Arabic`) تُرسل `TEXT` غير مُشكَّل لنفس طابعة XP التي ترفضه صمتاً — **نفس عيب الملصق قبل PRT-02**، لكن في التذاكر. أي تذكرة عربية عبر spooler اليوم = ورقة فارغة/خردة صامتة.

**الثغرة T2 — السطر البشري المكرر:** `BARCODE …1,0…` (تلقائي) + `TEXT` سفلي = رقمان مكدسان (نفس ما أُصلح في الملصق).

**الثغرة T3 — `TOTAL TTC` مبكسل:** `"3",2` مكبّر (نفس ما أُصلح في الملصق بالوجه `"5"`).

**الملاحظة T4 — `Sous-total` و`HT` يعرضان نفس القيمة** (`subtotal_ht` مرتين). قد يكون مقصوداً (عرض TTC شامل)، لكنه يحتاج قراراً موثقاً لا تخميناً.

### 1.3 تذكرة graphique — `buildTicketPrintHtml` + `printTicketDocument`

نقاط القوة: RTL حقيقي، هروب HTML، باركود SVG، `@page 80mm`، انهيار الفراغات (مرآة TSPL).
الفجوات: **حقيقتان متوازيتان** (HTML ≠ بايتات TSPL — نفس التذكرة تطبع شكلين مختلفين حسب الناقل)؛ وحدات باركود SVG لا تطابق وحدات الطابعة (`moduleWidth 2` بكسل ≠ `2` نقاط) → تباين مسح؛ حوار OS بلا هوية بصرية.

### 1.4 مستندات A4 — `document-print.css` + `printing-a4`

العزل سليم (إخفاء التطبيق، ترويسة جدول مكررة). خارج النطاق ما لم يُطلب.

### 1.5 المعاينات

معاينة الملصق SVG تقريبية (`silentLabelPreviewSvg`)؛ التذكرة بلا معاينة بصرية (زر يطبع مباشرة). **لا شيء منهما مُشتق من البايتات.**

## 2) معايير الأنظمة الكبرى (للمقارنة)

1. **مصدر واحد للحقيقة:** المحرك يُنتج البايتات، والمعاينة تُشتق منها (لا قالبان).
2. **فشل صاخب:** لا ورقة صامتة أبداً — أي سطر غير قابل للطبع يُرفض قبل الإرسال.
3. **قابلية المسح:** هدوء `≥10` وحدات، ارتفاع شريط `≥15%` من العرض، سطر بشري واحد.
4. **ترويسة قانونية:** حقول ضريبية/سجل قابلة للطي عند الفراغ (موجود)، **وتُستكمل مع المحاسب** (NIF/NIS/AI/RC مرشحة — لا أُثبت قانوناً من عندي).
5. **إصدارات القوالب:** إعادة طباعة مستند قديم تُثبّت نسخة القالب الأصلية.
6. **معايرة الأسطول:** إزاحة x/y لكل طابعة + نقشة اختبار.

## 3) المقترح — 6 مهام مُرقّمة

| المهمة | المضمون | معيار القبول |
|---|---|---|
| **DOC-01** | توجيه العربية في التذاكر للنقطي (مرآة PRT-02: `needs_bitmap` لخانات التذكرة + تنقيط في `PrintTsplTicketUseCase`) | تذكرة عربية تُطبع وتُقرأ؛ اختبارات ذهبية؛ `hermes` حارس صاخب |
| **DOC-02** | تذكرة TSPL v2: سطر بشري وحيد + `TOTAL TTC` وجه أصلي + قرار موثق لـT4 | بايتات ذهبية + `Printed` سبولر |
| **DOC-03** | مُصيّر معاينة من البايتات (TSPL→SVG: `TEXT/BARCODE/BITMAP`) للملصق والتذكرة | المعاينة بكسل-بكسل من نفس البايتات؛ يقتل «المعاينة تكذب» |
| **DOC-04** | إصدار القوالب (`template_version` في مسار الطباعة؛ إعادة الطبع تُثبّت الأصل) | اختبار: مستند قديم يُعاد طبعه بالهندسة القديمة |
| **DOC-05** | ملصق v2 (مراجعة صندوق العربية + هدوء) + ترويسة قانونية بعد تأكيد المحاسب | صور حية + `bytes_sent` مُثبتة |
| **DOC-06** | معايرة الطابعة (إزاحة x/y + نقشة اختبار في صفحة الطابعة) | نقشة تُطبع وتُقاس بالمسطرة |

الترتيب المقترح: `DOC-01` ← `DOC-02` ← `DOC-03` ← (`DOC-04` ← `DOC-05` ← `DOC-06` حسب الأولوية).
نماذج بصرية تقريبية في `mockups.html` (المرافق) — **ليست الحقيقة؛ الحقيقة = البايتات.**

## 4) المخاطر والحدود الصادقة

- DOC-03 مُصيّر جديد (أسابيع نسبياً) لكنه الوحيد الذي يقتل فئة «تختلف عن المعاينة» نهائياً.
- T4 يحتاج قرار مالك/محاسب قبل التنفيذ — لا ألمسه تخميناً.
- العربية في الإيصالات كانت مؤجلة بأمرك — DOC-01 يعيدها كبند حرج (ورقة صامتة)، والقرار لك.
- `hermes verify` محظور بيئياً (`approve-builds`) — البوابات المباشرة هي الدليل حتى يُحل.
