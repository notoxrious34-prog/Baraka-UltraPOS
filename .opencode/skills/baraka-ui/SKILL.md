# Baraka UI Skill
Use for React/Tailwind/Shadcn POS and application UI.

- Presentation never accesses the database directly.
- Follow the approved Industrial Trust / Silent Cockpit direction.
- Keyboard-first, touch-ready, RTL/LTR safe.
- Use design tokens; do not scatter raw colors in components.
- Financial values use dedicated MoneyDisplay patterns.
- Focus states and accessible names are mandatory.
- Avoid layout shift and unnecessary modal flows.
