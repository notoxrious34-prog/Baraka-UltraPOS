# مقترح مؤجَّل: صفحة تخصيص طباعة التذكرة والملصق

- **الحالة:** مُوثَّق ومُؤجَّل — لا يُنفَّذ حتى أمر صريح.
- **التاريخ:** 2026-11-08.
- **المصدر:** اقتراح المالك + دراسة تفاعلية (4 أسئلة مُجابة).

## 1) القرارات المُثبَّتة بإجابات المالك

1. **الوصل** = تذكرة البيع 80مم فقط (مسارا TSPL + Graphique)، لا الفواتير ولا الكشوفات.
2. **بطاقة الكود بار** = ملصق المنتج 40×20 الحالي (ماركة/اسم/سعر/عملة/باركود).
3. **العمق** = حقول ونصوص جاهزة (إظهار/إخفاء + تعديل نصوص) — لا محرر مرئي، لا شعار.
4. **المعاينة** = إلزامية، تُرسم من بيانات المحرك نفسه (عقيدة DOC-03).

## 2) الواقع الحالي (نقاط التثبيت)

- التذكرة: تخطيط مثبت بالكود — `crates/domain/src/printing/tspl.rs` (المحرك)
  + `src/features/tickets/graphique-ticket.ts` (المرآة). التخصيص اليوم = هوية
  المتجر فقط (اسم/عنوان/هاتف/NIF/NIS/RC/AI + `ticketFooterMessage`).
- الملصق: تخطيط 40×20 مثبت (ماركة/اسم سطرين/سعر F5/عملة/باركود + بشري).
- الإعدادات: مفاتيح KV في جدول `settings` (بلا هجرات). الكتابة Admin فقط
  (`SystemSettingsManage`).

## 3) التصميم المعتمد للتنفيذ المستقبلي

- مفتاحا إعدادات `ticket_options` و`label_options` (إظهار/إخفاء لكل سطر +
  نصوص بديلة). الافتراضي = المطبوع الحالي بايت-بايت.
- بنية خيارات **واحدة** تُغذّي المُصيّرين معاً (درس DOC-05: أي مفتاح لمسار
  واحد = انحراف).
- إعادة الطبع تستخدم **لقطة الخيارات المخزنة مع الوثيقة** لا الإعدادات
  الحالية (درس DOC-04) — يتطلب حقل لقطة أو ترقيم نسخ الملف.
- نقطة معاينة على سابقة `preview_tspl_label`.

## 4) خطوط حمراء (غير قابلة للتفاوض عند التنفيذ)

1. الأرقام المالية تُطبع دائماً حرفياً — إخفاء المجموع/الضريبة/المدفوع ممنوع.
2. نصوص المستخدم لا تدخل أسطر الأرقام أبداً.
3. الإخفاء = انهيار تام بلا فراغات.
4. الكتابة Admin فقط؛ الإعدادات محلية لكل قاعدة.

## 5) الحقول المرشحة

- **تذكرة:** اسم/عنوان/هاتف المتجر، كل سطر من NIF/NIS/RC/AI، المستودع، أمين
  الصندوق، عنوان التذكرة، الباركود + البشري، التذييل، الشكر. شريط
  DUPLICATA وشارة الخصم: إظهارهما دائم (لا يُخفيان).
- **ملصق:** الماركة، سطر الاسم الثاني، العملة، السطر البشري، نص السعر.

## 6) مراحل التنفيذ (عند التفعيل)

1. مفاتيح الإعدادات + تحقق المدى (خلفي).
2. خيارات المُصيّر TSPL + انهيار Graphique + لقطة الوثيقة.
3. نقطة المعاينة + صفحة الإعدادات + i18n (FR/AR).
4. اختبارات المرآة لكل مفتاح + G1–G7 + التزام.

## 7) المخاطر المسجلة

- انحراف المسارين (المعالجة: اختبارات مرآة لكل مفتاح).
- تضخم المفاتيح (المعالجة: ملف مُصدَر واحد).
- توقع "تخصيص كامل" (المعالجة: نص واضح في الصفحة بأن الأرقام والتخطيط
  الأساسي ثابتان).
