Autorisation du gérant - approbation sur place

Le gérant saisit son code PIN dans ce dialogue. La session du caissier ne change jamais.

Note de relecture : dans l’application réelle, ce dialogue recouvrira tout l’écran grâce à un positionnement fixe (exception ADR-067 pour les fenêtres modales) ; dans ce fichier statique, chaque exemple utilise un positionnement absolu limité à sa propre section, uniquement pour permettre la relecture des quatre états sur une seule page. Le code PIN n’est ni stocké ni journalisé par l’interface.

Ce même dialogue est réutilisé pour les autres actions soumises à approbation (par exemple l’encaissement d’une dette) en changeant uniquement le texte de la ligne de contexte ; conformément à ADR-079, cette ligne ne montre jamais un montant ni un motif de refus de crédit, seulement le nom de l’action et une référence de document le cas échéant.

État un : dialogue initial, PIN vide (état focus simulé pour démonstration). La touche Échap annule et referme le dialogue sans valider.
