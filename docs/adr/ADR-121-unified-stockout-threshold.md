# ADR-121 — تعريف عتبة النفاد الموحدة (تعديل ADR-037)
**الحالة:** PROPOSED (يُعتمد مع BRK-120). **التاريخ:** 2026-11-15.
**السياق:** لم توجد وثيقة تعريف لـ ADR-037 (فجوة من صنف G-D8)؛ السلوك كان
مثبتًا بالكود والاختبار فقط. التدقيق البصري F-B2 كشف التعارض: التنبيهات
تخفي المنتجات النشطة بلا صفوف مخزنية بينما عدّاد Catalogue يحسبها نافدة.

## القرار (الخيار A المعتمد من المالك)
1. النفاد = `COALESCE(qty, 0) <= 0` لكل زوج (منتج نشط × مستودع نشط).
2. المنتج النشط بلا أي صف يظهر في التنبيهات بكمية 0 في كل مستودع نشط
   (هدف التعديل حقيقي لزر التسوية).
3. المنتجات/المستودعات غير النشطة خارج التنبيهات (مواءمة مع Catalogue).
4. التنفيذ: `UNION ALL` — الفرع الأول يحفظ دلالاته الحرفية؛ الثاني يضيف
   التغطية الناقصة فقط. الترتيب: الكمية ثم SKU ثم المستودع (حتمي).

## البدائل المرفوضة
- إبقاء التعريفين (التباس مثبت بصريًا F-B2) — مرفوض.
- تضييق Catalogue (يخفي نفادًا حقيقيًا) — مرفوض نطاقيًا.
