# مقترحات التعديل والإصلاح — v1.4.0 (موثقة دون تنفيذ — بانتظار الأوامر)
**المصدر:** `docs/design/VISUAL-AUDIT-v1.3.0.md` (السجل) +
`docs/audits/AUD-VIS-001-visual-inspection-report.md` (التقرير).
**القاعدة:** صفر كود حتى الأمر الصريح. كل مقترح: الهدف/النطاق/القبول/المسار/
المخاطر/التحقق/التقدير (S < يوم، M أيام، L أسبوع+).

## المسار R — إصلاحات (أولًا، بالترتيب)
### R1 — إعادة اختبار البيع الآجل يدويًا (AUD-061) — S
- **الهدف:** إثبات أو نفي العطل بسيناريو AUD-061 §4 (Espèces=0/Crédit=TTC).
- **القبول:** بيع آجل 586 + كتلة المعادلة في الدرج؛ الإصلاح (`BRK-118`) فقط عند
  إعادة الإنتاج باختبار يفشل أولًا.
- **المخاطر:** المسار المالي حساس — G1–G7 كاملة؛ بلا ترحيل إلا عند الضرورة (0023+).

### R2 — إعادة اختبار المخزون الافتتاحي يدويًا (AUD-061) — S
- **الهدف:** منتج جديد بمخزون 144 ومستودع صريح → تحقق `Stock = 144` + حركة دخول.
- **القبول:** الإصلاح (`BRK-119`) فقط عند إعادة الإنتاج؛ المسار مختبر 4/4 حاليًا.

### R3 — حزمة التسميات والتواريخ (F-B6/F-B8/F-B5/F-B10/F-B3/F-B9) — S
- شارة السطر `Super-Gros` (FR)؛ تنسيق التاريخ محليًا (درج + مستخدمون)؛ `X` واحد؛
  زر `Réimprimer` واحد؛ سياسة الائتمان خارج لافتة Caisse؛ تحميل تلقائي للتقرير.

### R4 — عتبة النفاد (F-B2) — S
- تعريف واحد معلن (صفر = نفاد؟) مطبَّق في Stock وCatalogue معًا.

## المسار P — بصريات (بعد R)
### P1 — Caisse (M): شريط جلسة سطرين؛ لافتة واحدة؛ شبكة (كتالوج|سلة|مجاميع
ثابتة)؛ `F12` رئيسي وحيد. **القبول:** لقطة قبل/بعد + مصفوفة FR/AR × فاتح/داكن،
صفر overflow. (يغلق F-A2/F-A6/F-B3)
### P2 — اتساق المودالات (S/M): الأسعار الأربعة إنشاءً وتعديلًا؛ معاينة RTL؛
إغلاق موحد. (يغلق F-A1/F-A4/F-B5)
### P3 — Catalogue الفارغ (S): سطر ملخص واحد + إصلاح `Tous0` + إخفاء الأعمدة بلا
صفوف. (يغلق F-A7)
### P4 — الأزرار (S): ارتفاع واحد + هرمية رئيسي/ثانوي/خطر عبر المشروع.
### P5 — هنات AR (S): `−0,00`؛ توحيد موضع `د.ج`؛ ellipsis البحث؛ تخفيف الشريط.
(يغلق F-B11)
