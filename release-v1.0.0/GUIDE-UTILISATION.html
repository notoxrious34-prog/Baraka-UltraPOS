1 · Artefact & Installation / ملف التثبيت

Fichier remis par le technicien : Baraka UltraPOS_1.0.0_x64-setup.exe (~211 Mo, 221 552 107 octets). Windows 10/11, aucune connexion internet requise.

SHA-256 :
C608C32A8C96B089CB51E187DE473AD0FCCD3E728E8B1C07D0311C1E65D75934

Double-cliquez (français proposé en premier), installez depuis le compte Windows de la caisse. Écran bleu SmartScreen attendu : « Informations complémentaires » → « Exécuter quand même ».

الملف: Baraka UltraPOS_1.0.0_x64-setup.exe (نحو 211 ميغا)، يعمل دون إنترنت على Windows 10 أو 11. ثبّته من حساب الصندوق. تحذير SmartScreen الأزرق متوقّع: «Informations complémentaires» ثم «Exécuter quand même».

2 · Premier démarrage & Configuration / أول تشغيل وضبط

  1. Créez le compte ADMIN (un seul) ; conservez le mot de passe en lieu sûr.
  2. Paramètres → « Identité & Impression » : nom, adresse, téléphone, identifiants fiscaux RC / NIF / NIS / AI (en-tête des tickets).
  3. Un magasin par défaut existe déjà ; ajoutez les autres depuis le module Stock.
  4. Basculez la langue FR/AR en haut (arabe affiché de droite à gauche).
  1. أنشئ حساب المدير (ADMIN) واحفظ كلمة المرور.
  2. الإعدادات ← «الهوية والطباعة»: الاسم والعنوان والهاتف والمعرفات الجبائية RC / NIF / NIS / AI (تظهر في التذاكر).
  3. يوجد مخزن افتراضي جاهز. بدّل اللغة FR/AR من الأعلى.

3 · Imprimante & douchette / الطابعة وقارئ الباركود

  • Recommandée : thermique 80 mm ESC/POS, port série ou COM virtuel. Notez le port (ex. COM3) dans le Gestionnaire de périphériques.
  • Renseignez port + débit, puis bouton d'impression de test (diagnostic sans effet comptable : aperçu + capture .escpos).
  • Faites le drill avec le technicien avant la mise en service (voir §6).
  • Douchette USB « frappe clavier » : branchez, cliquez dans la recherche, scannez.
  • الموصى بها: حرارية 80 مم ESC/POS عبر منفذ تسلسلي أو COM افتراضي.
  • اضبط المنفذ والسرعة ثم جرّب زر اختبار الطباعة (تشخيص دون أثر محاسبي).
  • نفّذ تجربة الطباعة مع التقني قبل التشغيل. قارئ USB يعمل مباشرة.

4 · Cycle quotidien / العمل اليومي

ÉtapeAction
1Ouvrir la session de caisse (fond de caisse compté).
2Vendre : scan/recherche, quantités, remise, espèces (rendu calculé) ou crédit client.
3F8 parque la vente, F6 la reprend.
4Dette : dossier client → encaissement, reçu سند قبض (trop-perçus bloqués).
5Clôturer : compter le tiroir, écart enregistré (rapport Z quotidien).

افتح الجلسة ← بِع (مسح/بحث، خصم، نقد أو دين) ← F8 تعليق وF6 استئناف ← تحصيل الديون بإيصال سند قبض ← أغلق الجلسة مع عدّ الدرج (تقرير Z).

5 · Données & sauvegardes / سلامة البيانات

Vos données vivent sur votre PC : %APPDATA%\com.baraka.ultrapos\baraka.db — installation, réinstallation et désinstallation ne les effacent jamais.

Sauvegardez depuis Paramètres → Sauvegardes et copiez le fichier sur une clé USB hors du magasin. Panne : réinstallez, restaurez (ADMIN), vérifiez une vente et le stock avant de reprendre.

بياناتك في %APPDATA%\com.baraka.ultrapos\baraka.db — لا يحذفها التثبيت أو إلغاؤه أبدًا.

انسخ نسخة احتياطية دوريًا على USB خارج المحل. عند عطل: أعد التثبيت واستعد آخر نسخة ثم تحقق قبل الاستئناف.

6 · Check-list du drill imprimante / قائمة تجربة الطباعة

  • Papier 80 mm, imprimante allumée, câble branché, port COM noté.
  • Test « capture seule » : aperçu correct (identité, NIF/NIS/RC/AI, totaux, coupe).
  • Test physique : papier identique à l'aperçu.
  • Tolérances : USB débranché / éteinte / sans papier → badge propre.
  • Ligne signée (date, opérateur, modèle, COMx, OK) — sans elle, mise en service non clôturée.
  • الورق والطاقة والكبل ومنفذ COM جاهزة.
  • اختبار التقاط فقط بمعاينة سليمة، ثم اختبار فيزيائي مطابق.
  • اختبارات التحمل بشارة نظيفة، ثم سطر موقّع في الجدول.

7 · Version 1.0.0-rc.5 — Nouveautés Quincaillerie & Commerce Général / الميزات الجديدة لتجارة العقاقير والتجزئة

1. Catégories & pack initial quincaillerie

7 catégories standards (plomberie, électricité, peinture, visserie, outillage, serrurerie, divers). Filtrez le catalogue par pastille, gérez les catégories depuis le module Catalogue.

2. Recherche phonétique intelligente

La recherche tolère le dialecte arabe/français et les fautes de frappe (« فيس بلاكو » trouve VIS-PLA-25) ; la douchette bascule l'unité automatiquement.

3. Cockpit multi-unités

Touche F3 : bascule pièce / boîte / sac / kg sur la ligne. L'équivalence en stock de base s'affiche (« = 300 Pièces »).

4. Tarification professionnelle & bouclier de marge

Attribuez à chaque client un niveau : Détail, Artisan / Pro, Gros (touche F2). Le panier re-calcule aussitôt les prix (badges PRO / GROS). Si une ligne passe sous le coût d'achat, une alerte pulsante ⚠️ Vente à perte affiche la marge exacte.

5. Import massif par CSV

Catalogue → Importer : déposez un fichier modèle_import_baraka_pos.csv (séparateur « ; »), contrôlez l'aperçu en 4 étapes, les doublons de SKU sont ignorés.

6. Identité visuelle officielle « Baraka »

Logo doré officiel dans la barre supérieure, la navigation, l'écran de connexion et la rubrique À propos — ainsi que l'icône de l'application Windows.

1. الفئات والحزمة الأولية للعقاقير

7 فئات معيارية مع فلترة سريعة وإدارة كاملة من وحدة الفهرس.

2. البحث الصوتي الذكي

يتسامح البحث مع اللهجة والأخطاء الإملائية، وقارئ الباركود يبدّل الوحدة تلقائيًا.

3. مقصورة تعدد الوحدات

زر F3 للتبديل بين قطعة / علبة / كيس / كغ مع عرض المكافئ في المخزون.

4. التسعير المهني ودرع الهامش

امنح كل زبون فئة: تجزئة، حرفي / مهني، جملة (زر F2) — تُعاد حساب الأسعار فورًا. عند البيع بأقل من التكلفة يظهر تنبيه نابض ⚠️ بيع بالخسارة مع نسبة الهامش الدقيقة.

5. الاستيراد الجماعي عبر CSV

من الفهرس: أفلت ملفًا بفاصل « ; »، راجع المعاينة، وتُتجاهل الرموز المكررة.

6. الهوية البصرية الرسمية «بركة»

الشعار الذهبي الرسمي في الشريط العلوي وشاشة الدخول وحول التطبيق وأيقونة ويندوز.
