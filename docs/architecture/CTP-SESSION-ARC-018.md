### Modification 2: Safe Deletion of Products, Warehouses, Suppliers, Customers
- **STATUS: AUDITED (TASK-AUD-005), READY FOR IMPLEMENTATION**.
- **Architectural Fact:** Tables `products`, `warehouses`, `suppliers`, `customers` have `is_active` column in schema 0001. Foreign keys (`ON DELETE RESTRICT`) and append-only triggers prevent hard DELETE on rows with historical documents/movements/ledger rows.
- **Decision:** Dual-Track Safe Deletion:
  1. If entity has zero foreign references: allow permanent Hard Delete.
  2. If entity has historical records: perform Soft Deactivation (`is_active = false`), hiding from active dropdowns, POS search, and lists.
  3. Safe-guard invariants: `DEP-01` cannot be deleted/deactivated; customer with balance > 0 cannot be deleted/deactivated.
  4. Engine requirement: add `warehouses_update` IPC command (`is_active: bool`) since warehouses currently lack an update command.

### Modification 4: Pack Quincaillerie Générale (300 items) Install & Uninstall

- Solution: Add setting key `fiscal.timbre_enabled` (default "true"). When "false", `compute_timbre` returns 0 centimes. Add toggle switch in Settings -> Fiscalité / Configuration.
