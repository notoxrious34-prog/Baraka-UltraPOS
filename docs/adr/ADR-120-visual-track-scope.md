# ADR-120 — نطاق المسار البصري v1.4.0 (نتيجة AUD-VIS-001)
**الحالة:** PROPOSED (يُعتمد مع V0-3). **التاريخ:** 2026-11-15.
**السياق:** 18 نقطة بصرية موثقة (`F-A/F-B`) + أحكام AUD-060/061.

## القرار
1. النطاق: P1 (Caisse) → P2 (مودالات) → P3/P4 (Catalogue/أزرار) → P5 (AR) +
   R3 (DSN-107: تسميات/تواريخ + عرض آخر معاينة ناجحة) + R4 (BRK-120: عتبة النفاد).
2. Visual gate إلزامي لكل مهمة: مصفوفة FR/AR × فاتح/داكن + لقطة قبل/بعد.
3. `DSN-113` (زر التحويل من الوثيقة — دلتا AUD-060) ضمن P2.
4. خارج النطاق: أي تغيير محرك/ترحيل؛ الطباعة الورقية (بانتظار بيئة).

## البدائل المرفوضة
- إعادة تصميم شاملة دفعة واحدة — مرفوضة (خطر انحدار؛ التدرج P1→P5 إلزامي).
